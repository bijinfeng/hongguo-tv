# Proposal

## Why

现有详情已能浏览选集与切季，但固定上游提供的演员和相关推荐尚未进入 Rust 契约和共享页面。补齐原型中选集之后的两段内容，让用户能从详情进入演员作品和相关短剧，同时保持安静观看、真实数据与来源返回。

## What Changes

- 新增独立完整详情 DTO，包含演员和相关作品；公共剧集摘要、历史记录保持原有边界。
- 从固定上游的 router JSON 与延迟推荐 JSON 读取扩展，不执行网页脚本，不迁移用户排除的剧评。
- 详情按当前季展示演员入口与相关海报；无 ID 演员展示姓名，空数据隐藏相应段落。
- 补齐完整性、取消、切季、后台、返回焦点和较后条目的回归，分别审查功能与 UI。

## Capabilities

### New Capabilities

- `detail-discovery`: 有界完整详情、演员入口、相关作品与当前详情身份的所有权。

### Modified Capabilities

无；当前主规格目录尚无已归档 capability。

## Impact

影响 core catalog、HTTP/native 详情路由、生成契约、共享详情状态与页面、测试夹具及验收工具。保留现有 Rust 简要详情调用兼容，不增加依赖，不修改 upstream；不包含评论、弹幕、评分、推荐分页或账号写操作。
