# 红果短剧 · 官网风格预览

当前TV重设计入口为[tv-v4.html](tv-v4.html)，规则与审阅／验收边界统一见[设计说明](../../../docs/design/tv-redesign.md)。下述旧TV原型仅用于既有生产布局对照，不作为此次重设计依据。

独立视觉比较预览，采用[红果短剧官网](https://hongguoduanju.com/)的黑色层级与红果橙动作色。目录、分类、集数和可用海报来自官网公开内容；播放、片单和账号状态是本地演示，不接入真实视频或生产服务。

## 浏览

直接打开 `index.html` 选择预览，也可打开各端文件。全部样式、脚本、Logo 和海报都在项目内，无运行时远程依赖。

| 文件              | 内容                                                                                                         |
| ----------------- | ------------------------------------------------------------------------------------------------------------ |
| `desktop.html`    | Web / 桌面：发现、榜单（红果榜／榜单雷达）、找剧、详情、选集、模拟播放器、记录、收藏、追更、预约、账号与设置 |
| `tv.html`         | Android TV 1920×1080，自适应缩放、方向键焦点、内容轨道、榜单（红果榜／榜单雷达）、详情选集面板、播放器       |
| `components.html` | 浅深色并列的基础组件与状态                                                                                   |

榜单原型演示：`desktop.html?rank=radar` 或 `tv.html?rank=radar` 打开榜单雷达（官方快照），`?rank=radar&view=growth` 为飙升榜，`?state=loading`、`?state=empty`、`?state=error` 分别展示加载、空榜与刷新失败态，`?theme=light` 为浅色。页内可直接点“红果榜／榜单雷达”切换来源，雷达内可切视图、分类、排序与类型；桌面用表格右上的 ‹ › 横向查看列，TV 列宽按 1920 全宽排布、方向键上下移动行。TV 榜单入口在顶部导航“排行榜”，红果榜为 hero + 榜单类型 + 双列榜单行，雷达为控件带 + 全宽表格。雷达数值为设计样例，不来自官网。

页面上方可切换端。太阳按钮或设置页可切换浅深色；组件板同时展示两种主题。

桌面：搜索剧名或分类，使用标签筛选与排序；点击海报进入详情，选择剧集或开始模拟观看。长剧集按每组 40 集浏览。收藏、追更与预约后续只变更此预览的个人片单；预约不代表官网有后续上线计划。

TV：方向键移动焦点，Enter 确认，Esc / Backspace 返回。详情面板限制焦点，关闭后返回入口。选集按每组 24 集浏览。观看记录直接续播；收藏页中可切换追更、预约，设置中可进入演示账号。播放器进度条使用左右键调整。

组件板：可点击标签页、复选框、开关、选择器、滑杆、弹窗与反馈按钮。覆盖默认、hover、pressed、selected、focus、disabled、pending 和 error；禁用控件不触发操作。

不展示评论、回复、弹幕、剧评、点赞或任何社交指标。不导入官网的评分、热度、评论或榜单排名数字。

只用 `night-theater:` 前缀的 localStorage 保存主题、演示片单与进度；真实目录版本使用 `library-real-v1` 键，与旧虚构目录隔离。不同 `file://` 页的存储共享取决于浏览器策略；通过同源静态服务浏览时共享。禁止存储时仍可在内存中操作。不会保存密码或发送账号信息。

## 编辑与验证

- `assets/catalog.js` 是目录与海报的唯一数据入口；跨端共享，布局分别维护。
- `assets/theater.css` 是主题、组件和桌面 12 列网格入口；`tv.css`、`components.css` 分别处理各布局。
- `assets/app.js` 维护桌面路由；`tv.js` 维护 TV 页面与焦点；`components.js` 维护组件状态。
- `PRODUCT.md` 记录范围；`brand-spec.md` 与 `DESIGN.md` 记录视觉合同。
- 运行 `node tools/verify.mjs` 校验本地入口、脚本语法、官网数据、集数、图片尺寸与来源。

已进行目录、资源、脚本与模拟 DOM 交互校验；真实视频、账号服务、实体 Android / TV 硬件不在此预览验证范围。所有修改仅位于本独立项目。
