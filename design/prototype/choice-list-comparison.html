ChoiceList

/** 一组可选标签：单一聚焦组。 */
function ChoiceList(props: {
  label: string;      // 组的可访问名称
  value: string;
  items: ChoiceOption[];
  onChange: (value: string) => void;
  testID?: string;
  onSource?: (restore: () => void) => void;
  onNavigate?: () => void;
  onPrimary?: (ref: ViewRef) => void;
})

首页用。无标签列，换行。

LabeledChoiceList

/** 同一组标签，前置一列名称。 */
function LabeledChoiceList(
  props: ChoiceListProps & {
    title: string;
    onOptionFocus?: (ref: ViewRef) => void;
  }
)

找剧、排行榜、上新日历、榜单雷达用。onOptionFocus 供排行榜做 reveal。

◆
href 之外只剩一处行为差异。排行榜在聚焦时需要把行滚进视口（row.reveal），并发一个 primary ref 给页面主焦点。这两个都做成可选回调，不写进样式，组件也不会因此分裂。
