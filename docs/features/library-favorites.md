# 观看记录与收藏

正式页面沿用 [DESIGN](../../DESIGN.md) 的本机记录管理、详情选季及公共控件规范；视觉来源仍是[基础组件板](../design/component-design.md)。共享片库只有一个 Tabs、虚拟列表和管理控制器，历史与收藏保留各自 ID＋offset 阅读锚点。收藏只显示真实摘要，不借用历史进度；详情操作只指向当前浏览季的精确 series。

## 动效清单

- “观看记录／收藏”使用公共 Tabs 的选择、hover、pressed 和 focus-visible；切换保留各自阅读锚点，重置页面选择与确认呈现。即时恢复列表位置，不新增滑屏或入场动画；新输入、后台、离页和 owner／epoch 变化取消迟到焦点恢复。
- 历史与收藏行复用 ResultCard、Cover、Checkbox、Button 和现有间距；管理密度切换仍按稳定 ID＋offset 恢复。收藏行没有观看进度或虚构播放状态，封面失败使用公共 Cover fallback；虚拟行回收不重播入场。
- 单项取消收藏与本机清空复用 ConfirmDialog 的既有淡入／淡出、安全初始焦点和回源；选中、禁用、pending 使用公共控件反馈。账号单项取消会同步至账号，本机清空不批量取消远端收藏；结果只在持久回执后更新。
- 详情的“收藏／已收藏”复用公共 Button 的选中、hover、pressed 和可见焦点，使用官方 Lucide bookmark。提交中不乐观改变 membership；失败／未确认文案在原动作区下方更新，原 operation 的明确重试不改变 desired state。切季与重新挂载不播放庆祝或额外入场，不抢回焦点。
- 详情与片库仅在账号同步中、待处理或失败时显示公共 Notice，状态原位即时更新，提供“查看同步”到已有账号入口；不把本机收藏回执说成单项云端同步成功。账号页、详情和片库复用同一个前台只读观察器，后台与离页停止观察。
- 账号页 AccountLibrary 沿用共享 Button 的既有反馈；同步状态文字与导入计数原位即时更新，不因轮询重排行块。导入确认沿用 ConfirmDialog presence 与安全取消，回到存活来源，候选归零则回观看记录入口；离页不撤销已接纳导入，也不以迟到结果抢回焦点。无额外手势、声音或连续装饰动画。
- 上述控件沿用 fast／base token 和 reduced-motion；减少动态时取消位移、缩放并即时反馈。两端共用行为，仅适配已有布局与主题密度，不新增声音、装饰动效或第二套控制器。

## 验证边界

需要分别观察 Web、macOS 和 TV 的浅深色、长标题／封面失败、大字、键盘／DPAD、较后虚拟行、邻项回源与减少动态。正式入口真实数据和实际流程才是功能验收；合成边界回归、headless、静态截图各自只证明相应范围。当前实施与回归结果交由批次验收记录维护，本页不提前宣称通过。
