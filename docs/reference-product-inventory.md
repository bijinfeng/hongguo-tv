## 1. 产品结构

参考产品采用固定侧栏与内容区。首页以可直接观看的视频流为主体；其他发现入口主要通过海报、榜单和日历寻找内容，卡片可以直接开播，详细信息与选集在播放器中继续展开。

## 3. 详情、演员与系列剧

详情以播放器内弹层承载，包含封面、标题、简介、收藏和追更操作，以及演员区域。内容页签为“选集／系列剧／剧评／相关推荐”。

| 功能       | 已接入行为与边界                                                                                  |
| ---------- | ------------------------------------------------------------------------------------------------- |
| 选集       | 显示集数及当前播放／续播状态；直接切集；下一集到来时更新高亮和续播状态，保留面板                  |
| 演员       | 头像和姓名，支持展开全部演员；有演员 ID 时打开演员作品列表；缺少身份时仅展示信息                  |
| 演员作品   | 独立弹层、加载／错误／重试、作品选择与返回；可从榜单或详情进入                                    |
| 剧评       | 展示详情返回的整剧评价，与当前集评论是不同内容；不把当前集评论当整剧剧评                          |
| 相关推荐   | 使用当前剧详情中的相关内容，选择可进入播放                                                        |
| 系列剧     | 进入页签才读取官方完整季列表；显示季标签、当前季、继续播放及待上线状态                            |
| 手动切季   | 先取得目标季详情，再恢复该季历史；成功后更新面板；失败保持原视频，不抢走返回来源                  |
| 自动下一季 | 当前季结束后寻找严格相邻的下一季；从第 1 集、0 秒开始；待上线季进入预约流程，不跨过去播放更远的季 |
| 下一季提示 | 全屏末集结束前约 3 秒，在已有目录数据足够时展示下一季卡片；不因此提前下载下一季                   |
| 创作者合集 | 支持与普通短剧不同的合集身份及完整上传目录；不能把官网单条 30 秒预览当完整目录或完整播放来源      |

## 4. 播放与续播

典型流程是：发现内容 → 卡片直接开播 → 播放中选集／查看详情 → 自动下一集 → 有相邻下一季则跨季 → 没有后继时展示相关推荐 → 返回原列表和原卡片。

| 能力         | 已接入行为                                                                                               |
| ------------ | -------------------------------------------------------------------------------------------------------- |
| 基础控制     | 播放／暂停、上一集／下一集、按 10 秒快进快退、进度定位、倍速、适用端音量、全屏                           |
| 清晰度       | 仅展示当前视频实际支持的档位及自动；切换保留时间和暂停状态；失败保留原视频；偏好本机保存                 |
| 自动清屏     | 实际播放后空闲约 4 秒隐藏控件；确认键先唤出控制区，不在同一次操作中同时暂停                              |
| 后台行为     | 暂停并保存；解析中的请求不会在后台突然起播；回到前台保持暂停                                             |
| 历史         | 真正播放后才写；周期性及暂停／退出保存集数、时间；重启可恢复                                             |
| 同季预取     | 稳定播放后只准备紧邻下一集；Android／桌面默认整集预下载，可改边播边下；webOS 固定边播边下                |
| 预取取消     | 暂停、缓冲、拖动、质量改变、切剧／账号及后台取消无效任务；预取失败不打断当前集                           |
| 切集过渡     | 同剧切集避免重显整剧海报；复用目标集预览或上一帧；提示随等待阶段出现，实际就绪后立即撤除                 |
| 完结推荐     | 独立播放页结束且无可续播后继时，展示详情中的相关推荐；可关闭、左右选卡、确认播放                         |
| 完结自动播放 | 推荐行首卡就绪后倒计时 30 秒；方向键、鼠标、滚轮、触摸、媒体键、失焦等用户介入取消本次倒计时，不自动重启 |
| 继续观看     | 侧栏卡片一键回到原剧、原集和保存位置；支持跨栏目和重启后的恢复                                           |
| 错误与诊断   | 播放重试；区分取源、网络、缓存、数据处理和解码阶段；用户可打开／刷新诊断，不要求分享凭据                 |

依据：[播放操作][player]、[下一集预取][prefetch]、[完结推荐][end-recommend]、[继续观看版本记录][continue-release]、[播放诊断][diagnostics]。

预取属于播放准备，不等于面向用户的离线下载管理；不能据此宣称支持整季下载或离线片库。

## 8. 交互规则：后续对照应检查行为

1. **卡片直接开播。** 找剧、榜单、历史等进入播放时保存来源；返回恢复页面条件、已加载内容、滚动及可用焦点。
2. **当前页和焦点分开。** 左右移动焦点不等于切换频道／筛选；确认才提交需要显式选择的动作。网格上下按行移动并尽量保持列。
3. **返回逐层处理。** 优先关闭当前弹层／控件或退出全屏，再回来源页，最后才到根导航和退出确认；具体按有效状态执行，不用固定返回次数代替。
4. **弹层管理入口与出口。** 选集、评论、输入、确认和诊断各自限定焦点；关闭后回可见入口；长列表跟随焦点滚动。
5. **追加保留上下文。** 接近底部自动加载，保留现有卡片和滚动位置；失败可在原位置重试；不以失败后的空内容冒充无结果。
6. **危险操作先确认。** 清空、删除等默认聚焦取消；失败不显示成功，清空范围与其他库隔离。
7. **后台不擅自续播。** 保存并暂停，取消失效请求；晚到的取源、切季和账号响应不能恢复旧内容。
8. **连续播放区分三层。** 同剧下一集、同系列下一季、完结后相关推荐分别判断；不能把推荐下一部当同剧下一集。
9. **通知不打断观看。** 更新与内容提醒避开播放和弹层，在普通页面再提示，保留可回查入口。
10. **设置与能力匹配。** 不支持的平台隐藏专属入口；装饰失败降级，不连带重启播放器。

依据：[TV 交互约定][tv-design]、[当前实现][app]及以上专项说明。早期 TV 设计中手动“加载更多”等描述已由较新的滚动追加实现替代。
