# 预约

预约独立于追更和收藏。正式账号入口查看“待上线／已上线”，日历安排与待上线季沿用同一预约动作。桌面和 TV 共用页面、控制器、身份及焦点策略，只使用 `size` 与主题 token 调整现有基础组件密度。

## 动效与交互清单

- 状态切换沿用日历的 CardControls＋selected Button，键盘／DPAD 在组内移动；状态按钮始终可用，作为 TV 的页面主焦点，不让网络加载阻断入口。较新输入取消旧恢复。
- 公共 Button 负责 hover、pressed、pending、selected、focus-visible，提交期间保留已确认值，不乐观切换预约；减少动态沿用控件政策。
- 首次列表由 ContentArrival 呈现，沿用 180ms／8pt entrance；刷新保留内容，虚拟行回收不重播，减少动态取消位移。
- 确认取消后即时更新，按稳定身份＋offset 保留阅读位置；来源已移除时聚焦存活邻项或当前状态按钮。详情返回先还原锚点，再 nearest 揭示来源；owner／epoch、状态分类、后台、离页和较新输入使旧恢复失效。
- unknown／unconfirmed 保留已确认成员与原绝对目标，在动作附近显示 Notice；刷新只读，重试须明确激活，不自动重放 POST，不显示假成功 toast。
- 预约页呈现真实标题、封面、简介、标签及服务端上线文案／秒级时间，不推测上线状态。待上线项目不提供播放；已上线仅在真实可播 Drama 存在时提供详情。缺少身份或元数据保留可用操作，不将预约 item ID 构造为 series ID。
- 日历安排保留收起／返回行为，只替换未开放占位文字为共享预约动作。待上线季保留选季和播放禁用语义；季目标使用接口给出的 series 预约身份，日历目标使用 item 身份。
- 无新手势、声音、连续动画或自定义图标。页面复用 Button、Cover、Notice、UiText、CardControls 和现有主题。

## 验证边界

合成数据仅覆盖分类、缺元数据／身份、精确 item／series、空／错／stale、unknown 显式恢复、回收及焦点竞态。实际功能验收须使用正式入口、真实账号预约数据与实际宿主；真实云写须具备适用授权。浅深色、大字、减少动态、键盘／DPAD、Web／Desktop／Android TV 和真机观察分别记录，未观察的清单不计通过。
