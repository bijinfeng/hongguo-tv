# 应用更新 · 可交互设计规格

范围：桌面和 Android TV 的浏览器交互原型，不接真实发行源、下载、权限或安装接口。沿用 DESIGN.md 与既有原型，不改 NSH 生产页面。版本、大小、更新说明均为虚构演示数据。

## 入口与布局

设置 → 关于 → 应用更新。桌面保留导航与设置上下文，状态、进度和操作原位变化；右侧列出本版更新。TV 使用大字号双栏页面，左侧操作、右侧更新说明，沿用既有安全边距、主题与方向键焦点。只保留一个主动作。

默认自动检查，用户决定下载；不默认自动下载。后台发现更新不弹窗，不打断播放。下载期间可返回找剧，回来时保留进度。检查与下载的进行状态由评审栏模拟，产品区域不出现“完成下载”等假能力按钮。

直达：`design/prototype/index.html?screen=updates`；TV 加 `&platform=tv`。顶部“更新演示”可覆盖正常、失败、能力不足和系统步骤。

## 状态与动作

| 状态                       | 主要反馈                     | 动作及下一步                                               |
| -------------------------- | ---------------------------- | ---------------------------------------------------------- |
| idle / checking            | 当前版本 / 正在检查更新      | 检查更新 → available；等待时允许返回                       |
| latest                     | 已是最新版本                 | 再次检查                                                   |
| available                  | 新版本、安装包大小、更新说明 | 下载更新 → downloading                                     |
| downloading                | 已下载量、百分比、可继续观看 | 桌面无取消能力；TV 可取消并回 available                    |
| verifying                  | 正在验证更新包               | 不显示安装按钮；完成后 ready                               |
| ready · 桌面               | 更新已准备好                 | 重启更新 → 保存进度 → 重启 → 核对版本                      |
| ready · TV                 | 更新已准备好                 | 安装更新 → 判断授权 → permission 或系统安装器              |
| permission · TV            | 需要允许安装应用             | 前往设置 → 系统步骤示意 → 返回应用；拒绝则保留此状态       |
| installing · TV            | 等待系统安装                 | 系统步骤示意中确认安装；取消返回 ready；重新打开后核对版本 |
| restarting / confirming    | 正在重启 / 正在确认版本      | 只有真实版本匹配才进入 success；演示用计时器替代           |
| success                    | 已更新到新版本               | 回到找剧；不以系统安装器打开作为成功                       |
| checkError / downloadError | 无法检查 / 下载中断          | 重试检查 / 重新下载                                        |
| verifyError                | 更新包验证失败               | 删除无效临时包后重新下载，不提供强行安装                   |
| spaceError                 | 空间不足                     | 管理空间（系统步骤示意），返回后重新下载并重新校验空间     |
| saveError · 桌面           | 观看进度未能保存             | 重试保存并重启；不强行重启                                 |
| installError · TV          | 安装未完成                   | 重新安装或返回；保留已校验安装包                           |
| manual                     | 当前安装方式需手动更新       | 前往公开 GitHub Releases 发行页，自行选择安装包            |

原型每平台独立保存状态，仅存在内存；刷新回演示初始值。异步模拟拥有代次标记，切换评审状态取消旧回调。离页不取消下载。生产逻辑必须把下载/安装状态放到宿主服务，进程重启后按安装包与实际版本恢复。

## 输入、返回与可访问性

- 鼠标、Tab/Shift+Tab、Enter/Space；TV 沿用方向键空间导航、Enter 确认、Esc 返回。主动作有可见焦点。
- 返回设置恢复到“应用更新”入口；直达页面没有历史栈时返回“关于”。下载期间返回不出现取消确认。
- 每次状态替换若原动作消失，焦点移到新主动作；进度数字更新不重建页面，不抢焦点。打开系统步骤示意时焦点留在 dialog，关闭后恢复触发点。
- 状态标题通过 polite live region 宣告，进度使用原生 progress；仅文字百分比静默更新，避免每个 tick 重复读屏。
- TV 主动作最低 60px（浏览器预览尺寸，非已验证 Android dp），正文至少 24px；电视目标 1920×1080，桌面检查 1280 与 1440 宽。此范围不设计手机页面。
- 系统设置和安装器均明确标为“系统步骤示意”，不假冒真实系统窗口；安装取消和授权拒绝均可安全返回。

## 动效清单（编码前）

| 变化                       | 工具与 token                                          | 减少动态效果                     |
| -------------------------- | ----------------------------------------------------- | -------------------------------- |
| 按钮 hover / press / focus | 沿用已有控件颜色反馈，fast 100ms；焦点即时            | 颜色和轮廓立即变化               |
| 更新状态标题与动作替换     | 原位直接替换，不做位移动画，不加成功彩屑              | 相同                             |
| 页面进入与返回             | 沿用 enter 180ms / ease；不对各区块分别动画           | 禁用进入动画                     |
| 下载进度                   | progress 值反映模拟字节，数值使用等宽数字；不循环发光 | 相同，无平滑过渡                 |
| 检查、校验、确认版本       | 文字状态与静态图标；不以转圈代替进度                  | 相同                             |
| 系统步骤 dialog / toast    | 沿用既有 overlay 与 toast；仅用户点击打开             | 沿用既有 reduced-motion 禁用规则 |
| 布局、选择、拖拽、持续装饰 | 无新增；平台切换沿用现有评审工具                      | 相同                             |

## 后续 NSH 接入边界

共享更新状态、文案与错误恢复语义放 packages/app；可复用控件与主题放 packages/ui；apps/* 只注入宿主能力。桌面适配 NSH updater；TV 适配 Android 下载、APK 校验、未知来源授权和系统安装。浏览器原型的模拟状态不能作为生产更新业务实现。

生产能力必须提供：平台/架构/渠道、实际版本、检查/下载状态、可取消性、安装授权、恢复失败原因；不把签名、SHA 或流水线详情放主界面。公开源码与公开 GitHub Releases 不等于免签名校验。
