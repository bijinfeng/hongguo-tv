# 第二轮 UI 设计

> 2026-11-14 范围更新：本文保留历史研究／验收记录；当前设计以 [真实性审查](reality-audit.md)、[页面地图](ui-map.md) 为准。评论、回复、弹幕、剧评、点赞已由用户排除；离线任务与任意缓存容量未获证据支持，不能从本文恢复为当前要求。

范围：可点击浏览器设计原型，Web／桌面与 TV 两套独立界面。完整业务范围沿用 PRODUCT.md；所有剧目、播放、互动、账号和下载均为明确标注的本地演示状态。生产 NSH 页面不在本轮改动中。

## Direction contract

THESIS: 让用户用熟悉的视频产品操作找剧、接着看；TV 单独围绕遥控观看组织。

OWN-WORLD: 延续暖白／墨绿灰、深红／珊瑚红、系统字体、12px 圆角和平面边界。封面承担内容表达；桌面保留紧凑工具区，TV 为远距离观看提供独立字号、间距和焦点。

STORY: 首页续播；找剧和搜索进入详情；刷剧直接观看；选集、评论和返回保留上下文。历史、收藏、点赞、追更、预约、下载、账号、设置和附属入口全部可达。

FIRST VIEWPORT: 桌面为侧栏、顶部搜索、两条紧凑续播卡和海报内容架；播放页由画面和选集／评论上下文区组成。TV 为顶部主导航、当前续播的内容展示区和横向海报行；播放进入独立全屏画面与遥控控制层。

FORM: 用户明确要求借鉴成熟产品；桌面从 Jellyfin Web／FreeTube 取结构，TV 从 Infuse／Jellyfin Android TV 取层级与焦点模型。沿用此前已选的“续播与发现”任务方向，seed:56ef5b842742722f；此轮不再进行随机视觉选型。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 页面地图

| 层级       | Web／桌面                                      | TV                                                   |
| ---------- | ---------------------------------------------- | ---------------------------------------------------- |
| 内容主导航 | 首页、刷剧、找剧、排行榜、新剧                 | 精选、找剧、追剧、我的；搜索和设置独立可达           |
| 首页       | 紧凑续播、推荐海报、上新预告                   | 当前续播展示、横向推荐；焦点可进入主导航             |
| 找剧       | 搜索结果、类型／题材／排序、网格               | 分类浏览、海报行、搜索输入页；榜单和新剧作为栏目入口 |
| 详情       | 封面、简介与主动作，分季分段选集               | 远距离简介和播放主动作，独立选集区域，遥控分段定位   |
| 播放       | 桌面视频与右侧选集／评论并排；全屏按需打开面板 | 独立全屏、可收起控制层、进度定位、选集／评论侧面板   |
| 片库       | 继续观看、收藏与点赞、追更与预约、下载         | 我的内分栏目进入；追剧保留主导航入口                 |
| 账号与设置 | 桌面表单与分类列表                             | 大尺寸选项与独立焦点路径；原登录分支和维护入口均保留 |

TV 主导航是本轮的可评审方案，非行业通用规则。更多功能通过栏目归拢，不能因为未在一级导航出现就遗漏。

## Motion inventory

| 状态变化             | 工具及语义                                           | 减少动态效果   |
| -------------------- | ---------------------------------------------------- | -------------- |
| 桌面页面切换         | 主区 180ms ease-out，轻量进入                        | 即时显示       |
| 按钮与选集状态       | 100ms 背景／边框过渡；不改变布局                     | 即时换色       |
| 桌面选集／评论       | 原位切换固定上下文区，焦点留在触发标签               | 相同，无位移   |
| TV 内容焦点          | 清晰外轮廓，当前选中保留独立底色；不放大推挤相邻卡片 | 相同           |
| TV 控制层            | 180ms 透明度；隐藏后移出焦点树，确认键重新唤起       | 即时显示／隐藏 |
| 选集／评论／登录弹层 | 原生 dialog，180ms 进入；关闭恢复触发焦点            | 无位移         |
| 进度定位与任务状态   | 用户输入直接更新，无虚假进度动画                     | 相同           |

## 工程与验收边界

原型以共享演示数据和动作处理为核心，桌面、TV 分开编写页面与布局；不把 TV 写成桌面 CSS 放大模式。不新增框架依赖，不修改生产 NSH/Rust，不提交或推送。

检查桌面、TV 的页面与关键状态、键盘流程、焦点恢复、长选集、主题和减少动态效果。窄窗不是产品形态，不进入设计或验收。TV 浏览器模拟不证明真实遥控、观看距离、解码、安装包、系统频道或辅助技术通过。

## 质量依据与交付

以 [参考产品研究](ui-reference-products.md) 的实际图片和源码行为作为质量依据：桌面采用片库与并行播放上下文，TV 采用远距离内容层级与焦点恢复；不把手机截图当作桌面证据，也不声称旧版产品截图反映当前全部行为。用户已经指定成熟产品方向，本轮保留既定视觉身份，不再开启视觉风格竞赛。

质量检查关注主任务是否易找、海报与文字层级是否清晰、长选集是否可定位、TV 焦点与选中是否区分、返回是否恢复上下文。可点击产物为代码原型，没有全页效果图复刻义务。最终规格见 [prototype-system.md](prototype-system.md)，浏览器范围的终审见 [redesign-review.md](redesign-review.md)。
