当前范围与问题处理见 [本轮真实性审查](reality-audit.md)。

2026-11-14 现实约束纠正：页面只保留用户当前范围内、固定上游已有行为和真实数据能支撑的能力；下面的目标状态不代表已经迁移或在线验证。已证实但未迁移的能力继续保留，尚无依据的离线下载转待核对，五轴雷达评分取消。原型演示与此处冲突时按此范围修正，不为演示补造接口。

## Web／桌面导航分组

- 内容发现：首页、刷剧、找剧、排行榜、新剧。
- 我的片库：继续观看、收藏、追更与预约；离线下载待证据确认后再决定入口。
- 固定辅助入口：账号、设置；支持与应用推荐放在设置/关于的可发现位置，保留独立内容页。
- 详情、播放、选集和登录是带来源的流程，不重复添加到主导航。

导航命名保持一致：列表入口用“继续观看”，记录管理区使用“历史记录”；动作区分收藏、追更、预约，不将不同状态混成一个喜欢按钮。

## 关键流程

1. 找剧 → 筛选或搜索结果 → 详情 → 选集/播放 → 返回详情 → 返回原结果、原滚动与原卡片焦点。
2. 刷剧 → 当前内容播放 → 选集面板 → 关闭面板回到触发控件 → 下一部，保留原推荐频道。
3. 继续观看 → 恢复集数与时间 → 下一集/下一季 → 保存实际播放进度；退出后保留续播入口。
4. 游客关注/预约 → 登录流程 → 返回原任务，写操作由用户再次明确触发，避免登录后隐式重放。
5. 登录 → 账号独立记录与同步状态 → 同步失败保留待同步项 → 退出恢复游客本机记录。
6. 清空记录/取消预约 → 明确对象和影响范围 → 取消或执行；本机清空与云端删除分别表达。
7. 登录后显式合并登录前历史 → 只合并符合规则的较新记录 → 保留游客原记录；退出后仍可查看，失败不伪装为已同步。

真实边界：详情 actors／related 按响应显示，不用其他样例补齐；reviews 虽是上游真实字段，因用户排除而不展示。系列显示当前播放季与浏览季，预告／预约 ID 不当成可播视频，完整性不足不推算总季数。观看统计按实际观看累计并可单独重置，不由历史列表推算，也不承诺云同步。清晰度按片源提供，下一季按真实关系确认；原生解码／影院／预取设置按宿主能力出现，Web 不复刻缺失能力。

## 平台与输入

Web/桌面支持键鼠，导航可折叠并保留当前任务与可访问入口。产品不支持窄窗形态，不为窄窗保留独立入口或布局。TV 的页面地图、主导航、观看流程和焦点状态独立设计，见 [TV 设计简报](tv-design-brief.md)。上表是共享功能清单，不要求 TV 逐页复用桌面结构。

返回按当前上下文消解：先关闭最上层面板或对话框，再恢复操作层/退出全屏，再返回来源页面；根导航提供退出确认。具体控制栏显隐及确认键行为与上游行为逐项核对，原型不等于真机验收。

## 本轮原型验收

- 主导航覆盖完整页面地图，核心观看流程可点击往返。
- 浅色/深色、桌面和 TV 布局可审阅；窄窗不在产品验收范围。
- 推荐、搜索、详情/选集、播放与面板、个人片库、账号与设置均有具体内容和关键状态。
- 原型不发送登录、预约、打赏、下载或更新等真实写请求；这些操作用设计状态演示。
- TV 只演示布局与遥控交互模型，Android 安装、物理解码、系统频道和真实遥控留待 NSH 宿主验收。
