# 红果 UI 页面与流程

本轮交付：完整功能页面地图、可点击高保真设计原型，Web／桌面与 Android TV 作为两套独立界面方案，分别设计和审阅。产品范围沿用 PRODUCT.md；原型使用明确标注的设计样例，不连接真实账号或内容写接口。生产 NSH 界面与 Rust 迁移不在本轮改动中。

## Web／桌面导航分组

- 内容发现：首页、刷剧、找剧、排行榜、新剧。
- 我的片库：继续观看、收藏与点赞、追更与预约、下载。
- 固定辅助入口：账号、设置；支持与应用推荐放在设置/关于的可发现位置，保留独立内容页。
- 详情、播放、选集、评论和登录是带来源的流程，不重复添加到主导航。

导航命名保持一致：列表入口用“继续观看”，记录管理区使用“历史记录”；动作区分收藏、点赞、追更、预约，不将不同状态混成一个喜欢按钮。

## 关键流程

1. 找剧 → 筛选或搜索结果 → 详情 → 选集/播放 → 返回详情 → 返回原结果、原滚动与原卡片焦点。
2. 刷剧 → 当前内容播放 → 选集/评论面板 → 关闭面板回到触发控件 → 下一部，保留原推荐频道。
3. 继续观看 → 恢复集数与时间 → 下一集/下一季 → 保存实际播放进度；退出后保留续播入口。
4. 游客关注/预约/互动 → 登录流程 → 返回原任务，写操作由用户再次明确触发，避免登录后隐式重放。
5. 登录 → 账号独立记录与同步状态 → 同步失败保留待同步项 → 退出恢复游客本机记录。
6. 清空记录/删除评论/取消任务 → 明确对象和影响范围 → 取消或执行；本机清空与云端删除分别表达。

## 平台与输入

Web/桌面支持键鼠，导航可折叠，窄窗口保留当前任务与可访问入口。TV 的页面地图、主导航、观看流程和焦点状态独立设计，见 [TV 设计简报](tv-design-brief.md)。上表是共享功能清单，不要求 TV 逐页复用桌面结构。

返回按当前上下文消解：先关闭最上层面板或对话框，再恢复操作层/退出全屏，再返回来源页面；根导航提供退出确认。具体控制栏显隐及确认键行为与上游行为逐项核对，原型不等于真机验收。

## 本轮原型验收

- 主导航覆盖完整页面地图，核心观看流程可点击往返。
- 浅色/深色、桌面、窄窗口和 TV 布局可审阅。
- 推荐、搜索、详情/选集、播放与面板、个人片库、账号与设置均有具体内容和关键状态。
- 原型不发送登录、评论、预约、打赏、下载或更新等真实写请求；这些操作用设计状态演示。
- TV 只演示布局与遥控交互模型，Android 安装、物理解码、系统频道和真实遥控留待 NSH 宿主验收。
