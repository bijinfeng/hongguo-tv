## 找剧首屏

类型、题材、排序从十二个平铺筛选按钮收敛为三个具名原生选择框；全部原有选项仍可选。选中值直接显示，辅助名称由 label 提供，不增加解释标签。三个选择框在 TV 大视口横向排列，栏目入口移到结果之后，减少到达内容前的焦点停点。搜索入口、空结果恢复、排行榜、上新日历和刷剧均保留。

选择框 change 复用共享业务动作；页面重绘按控件 id 恢复焦点。选项和系统输入法的真实宿主交互需要另验，未把 Node 替身当作原生控件。

本轮没有新增动画或视觉身份。筛选、进度与评论原位更新沿用即时反馈；焦点外轮廓、影院控制层过渡及减少动态效果约定不变。动效清单在修改前已写入 `prototype-system.md`。
