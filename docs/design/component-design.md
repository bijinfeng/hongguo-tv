## 设计约束

现行公共规则以[根 DESIGN](../../DESIGN.md)为准；本交接补充组件组合与输入差异。必要控件边界使用 `input`，装饰分隔使用 `border`，不混为同一灰色；对比度与焦点裁切按根规范验收。

沿用既有暖白／深灰绿、红色主动作、系统字体与 12 圆角。普通操作为中性表面，主动作才用主色，危险动作以清晰动词与危险色表达。聚焦画外轮廓，选中改变底色并加可读标记；两者可以同时出现。TV 不显示悬停状态，也不以卡片缩放表达焦点。

样板以横向组件行呈现，展示标签属于评审工具，产品中不照搬“默认／按下／焦点”等说明。组件内容避免重复副标题。影院永远使用影院角色，即使页面是浅色。

| 公共组件                       | 共享契约与组成                                          | 桌面呈现                      | TV 呈现（1920 参考单位）                               |
| ------------------------------ | ------------------------------------------------------- | ----------------------------- | ------------------------------------------------------ |
| Button / IconButton            | 同一 press、disabled、pending、可访问名称；四种有限外观 | 普通 44，紧凑次要 36；图标 20 | 普通 60；图标 26；不使用紧凑档                         |
| Field / Input / Search         | 标签、值、输入、提交、清空、错误关联；不发请求          | 输入 44；键盘编辑             | 输入 60；确认进入编辑；返回保留草稿                    |
| Select / ChoiceGroup           | 单选值、预览、确认与取消；题材为单选语义                | 同一触发器与选项表面          | 同一触发器与选项表面，加大目标；不另造默认全屏选择流程 |
| Switch / Checkbox              | 立即偏好与多选语义分开；change 由调用方处理             | 44 点击目标内放轨道／方框     | 60 点击目标内放较大轨道／方框                          |
| Tabs                           | selected 与 onPress；焦点外观独立                       | 方向键激活，遵循 NSH 0.5      | 设计沿用同一激活意图；真实 TvRemote 路径仍待验证       |
| Notice / Empty / Loading       | 原位反馈、保留上下文、明确恢复；等待不冒充成功          | 原位提示、重试                | 同一提示与重试；文字足够持续读取                       |
| Dialog                         | 取消、确认、来源恢复；危险确认默认聚焦取消              | 宽 480                        | 宽 800                                                 |

颜色从 `packages/ui/theme.json` 生成到预览主题。尺寸与字体集中在设计 CSS 的两个端型档位，页面不复制变体。TV 的数值不是 dp/sp，也不代表简单缩放就通过了观看距离与系统大字号验收。

## 允许的输入适配

只保留三类有输入设备依据的差异，不增加两套业务流程：

1. 桌面具有 hover、鼠标拖动和 Tab 路径；TV 用方向、确认、返回，并常显必要操作。
2. TV 文本框区分导航与编辑，编辑／IME 时不得抢左右光标。浏览器只模拟此意图，不能证明系统中文输入法通过。
3. 滑杆共享 preview / commit / cancel。桌面释放拖动是提交边界；TV 必须先确认进入调整，避免横向导航误改播放位置，再确认或返回结束。

Select 的方向键只移动候选焦点，确认才提交；返回关闭后保留原值。单选题材与 Tabs 的组内方向直接激活，两端沿用同一组内规则。菜单与选择不是同一种语义，不建立万能弹层。

新增差异必须写明输入／宿主依据、共享行为不变量和验证方式。不能因为页面“像电视”就复制控制器、请求或状态机。

## 从设计到 NSH

设计样板的 `button / select / episodes / row` 等工厂与事件处理只有一份；两端没有独立 JS 文件。HTML 原生弹层和浏览器空间寻焦仅服务设计交互，不搬入 NSH。

原生实施沿用 [NSH 方案](nsh-components-plan.md)：`nsh/base` 拥有基础行为，`packages/ui` 拥有风格与输入适配，`packages/app` 拥有业务值与副作用，`apps/*` 只装配宿主。先复用 NSH 控件语义与已有 `SelectFocus`／来源停靠／焦点移除交接；不要用浏览器 DOM 或假想 focus props 替代它们。

Slider 的公共 commit 在 NSH 边界映射 `onChangeEnd({value})`，Tabs 使用每个 Tab 的 `selected/onPress`，Dialog 使用 `class/style`，Sheet／Popover 使用 `popupClass/popupStyle`。Base Button 的 variant／size／pending 是项目包装契约，不能直接传给 base。

Lucide 固定 `lucide-static@0.468.0` 官方SVG；保留原始几何、许可证和包／逐图SHA256，无运行时CDN或npm UI依赖。唯一资源源为 `packages/ui/assets/lucide/`；`pnpm ui:icons` 生成NSH几何、组件板与产品原型的图标映射，镜像溯源由生成器同步。

已补齐 Tooltip／Toast／Menu／Popover、文字／间距／表面／头像／标签、主导航／返回／分区／分页、搜索建议／只读／验证码／复选部分选中，以及海报／续播／结果行／记录多选。它们继承同一套表面、尺寸和状态。新增反馈均标为演示，不扩充评论、弹幕、点赞或离线剧集任务；应用更新包进度不等于离线剧集功能。

## 验证边界

本轮验证组件设计的浏览器渲染与交互。桌面 1440×1000、当前默认窗口，以及 TV 1920×1080 参考尺寸分别观察；深浅主题、禁用、等待、错误、空内容、焦点与选中、搜索、输入退出、Select、Tabs、弹层返回与恢复、定位预览／取消均按样板操作检查。截图保存在忽略目录 `.impeccable/review/components/`。

扩展后的基础／导航／内容／反馈分别检查桌面深色与 TV 浅色，无横向溢出，内容图片全部载入。新菜单的方向键、危险命令转确认、Popover 返回与来源恢复、搜索建议确认已操作。针对 924×873 的补充复核：搜索外壳、输入本体、清空与提交均为 60；桌面四者均为 44，边缘对齐。TV 确认键可切换普通、部分选中和记录复选框；管理行选择前后的文档坐标与尺寸不变。清空独立焦点不连带外框。

本轮新增设计模块通过 JS 语法与定向格式检查；原型既有 24 项回归测试本轮通过。生成主题文件不纳入手写样式格式检查。本轮未运行产品 NSH check/build，也未增加或改变依赖。

这不代替原生 NSH check/build、macOS 可见宿主、TV 输入法／遥控、系统 1.3 字号、读屏或媒体链路验收。浏览器空间寻焦不是 TvRemote 的证明。正式实施必须重新完成对应工程和宿主门禁。

## 补全覆盖与本轮修正

用户指出最初四组不全，因此补为八组，并保留公共基础独立入口。设计清单按现有任务覆盖，而不是把 NSH 所有组件逐一做成无业务用途的包装。

| 组         | 设计样例                                                                                  |
| ---------- | ----------------------------------------------------------------------------------------- |
| 基础       | 文字层级、等宽数字、长文、间距、表面、边界、分隔、图标、头像、状态标签                    |
| 按钮与选择 | 四种动作层级、尺寸、图标按钮、默认／悬停／按下／焦点／选中／禁用／等待、ChoiceGroup、Tabs |
| 输入与表单 | Input、Search、搜索建议、错误、只读、验证码、帮助、Select、Switch、Checkbox／部分选中     |
| 导航       | 桌面纵向／TV 横向主导航、返回、位置路径、分区、已知页数／未知总数分页                     |
| 弹层       | Dialog／ConfirmDialog、Sheet、Select 列表、Menu、Popover、来源焦点恢复                    |
| 内容       | Cover／失败占位、PosterCard、ContinueCard、ResultRow、记录多选、追加状态                  |
| 观看       | 影院按钮、进度／音量 Slider、倍速 Select、选集／区间／末集状态                            |
| 反馈       | 原位状态、确定／不确定 Progress、Skeleton、空／失败／追加失败、Toast、Tooltip             |

搜索组合只绘制一次边界和焦点：外壳拥有正常边框及输入焦点轮廓，内部 Input 不重复绘制；编辑底色属于整个输入组合。清空按钮独立聚焦时只画自己的焦点，不再连带包围外壳。该修正针对用户提供的 TV／924px 窗口截图，不以 1920 参考图替代复查。

输入和同排按钮共用高度规格：桌面 44，TV 60。组合搜索框由外壳控制总高度，边线以内描边绘制，不占用布局高度；外壳、内部输入、清空与搜索按钮均达到同档位高度。

TV 的确认键统一激活复选框，沿用同一 click/change 路径；桌面保留原生 Space。记录管理行在未选和选中状态使用相同内距，切换仅改变背景、前景与复选状态，操作目标不位移。

覆盖复查列出的九类页面组合、六组关键状态和独立累计统计已补入上述八组，具体实现、原始依据与验证边界见 [组件覆盖审查](component-coverage-audit.md)。集合与记录管理、发现类组合、账号与设置、边界状态按职责分模块，统一接入共享控制器；没有为桌面与 TV 建立两套业务交互。

新增组件分别在桌面 1440×1000、TV 1920×1080 浅深主题观察；924×873 再查搜索、数字键盘、边缘弹层和内容集合。长快照表在组件内横滚，TV 左右键可查看；不会撑宽整页。账号提交／失败重试、集合详情返回锚点、记录多选与删除交接、影院状态和选集范围的焦点路径均在浏览器操作检查。账号、验证码、手机辅助输入、预约与播放仅模拟状态，不宣称真实服务能力已接通。

2026-11-15 内容语言补充：卡片剧名使用 `content-title`（18／24），与面板 `title` 区分；Cover 使用 poster／inline／feature 有限取景，续播贴边图由外框裁切。基础样板将四种 Surface 改为同层比较，移除套卡示范；间距关系和图片安全区按根 DESIGN，不新增页面自由 token。
