# TV 重设计

状态：设计已确定，生产组件与页面已接线，整体验收进行中。本文是本次TV重设计的唯一设计说明；[竞品研究](./tv-reference-research.md)只承载外部证据，[OpenSpec技术方案](../../openspec/changes/compose-tv-v4-from-shared-components/design.md)与[任务清单](../../openspec/changes/compose-tv-v4-from-shared-components/tasks.md)承载实现决策和批次。生产视觉的实际映射以DESIGN.md及生成主题为准，实施与验收完成分别记账。

## 设计决定

从[竞品视觉证据](./tv-reference-research.md#公开截图)提炼信息结构，不复刻第三方品牌或素材：飞牛的紧凑顶部导航、连续内容行、集中详情操作与播放参数分层；小电视的内容优先、独立搜索工作区与遥控器浏览秩序。截图不能证明未展示的焦点行为；下述行为为红果自己的设计决定。

四个一级入口：**精选、找剧、榜单、我的**。搜索与设置位于右上；新剧／上新日历归找剧，历史／收藏／追更／预约归我的。详情收起主导航，只保留返回；播放为独立全屏。每层只有一个主动作，不用卡片堆叠解释页面，不永久显示遥控说明。

「我的」不再重复设置入口；头像与账号信息合为一个可聚焦入口，游客进入登录，已登录进入账号与同步，不另排一组同义按钮。

使用真实竖版封面，保持其原比例。没有真实横版剧照就不伪造背景。深炭灰用于暗光观看，橙色限于播放、进度和少量状态；白色外焦点框与填充式持久选择分开。浅色提供同一结构，不能只反转文字。

## 尺寸与组件契约

逻辑画布 960×540；对应本项目 API34 AVD 的 1920×1080 / density 320。浏览器原型由单一画布容器等比适配；720p、1080p、4K改变输出倍率，不改变控件的逻辑尺寸或自动增加列数。非16:9窗口居中留黑边，不拉伸、不裁切。浏览器CSS尺寸不直接称为生产dp，候选仍需原生宿主与实际观看距离验收。

[APK源码证据](./tv-reference-research.md#飞牛与小电视静态证据)记录飞牛的1920设计宽／density适配与小电视的多分辨率px资源。飞牛归一到960坐标后，导航18、片名14、辅助12、详情标题28支持本稿的尺寸方向；小电视卡片标题资源在960配置为14px。常规按钮36仍是红果候选值，不宣称是竞品统一规格。

腾讯、奇异果、酷喵、芒果及平台的适配方式见[厂商与平台证据](./tv-reference-research.md#其他厂商静态证据)。统一逻辑坐标、独立文字倍率和安全区已落实到原型与生产组件；未引入Android适配库或覆盖系统density。生产宿主仅承担必要的遥控与焦点适配。

| 项目     | 逻辑尺寸                                                                           |
| -------- | ---------------------------------------------------------------------------------- |
| 安全边距 | 标准横向36／纵向24，保守5%为48／27；操作区另留6供外焦点框使用                      |
| 文字     | 正文／片名14、辅助12、导航／栏目18、页面标题22、重点28；普通／主播放文字14         |
| 控件     | 普通控件sm32／md36／lg40；主播放／导航40、键盘36；均为最小高度，随文字增高         |
| 图标     | 官方 Lucide，18/20                                                                 |
| 网格     | 默认六列封面，间距16；大字减列，片名保留双行槽位，完整名称可由无障碍名称／详情获取 |
| 圆角     | 封面8、控件6、浮层12                                                               |
| 焦点     | 2逻辑像素外框，外偏移3；浅色使用深色框                                             |

普通控件档位来自组件化规划的映射，sm文字档位仍在原生样板核定；未在此声称全部档位已由浏览器原型或生产宿主验证。

候选视觉在实施时直接落在 `packages/ui` 的生产组件与 `packages/app` 的页面里，没有一份并行的候选样式表：控件、海报、输入、设置行、键盘与浮层皮肤都是组件本身，页面只排布局。组件板与页面共享同一实现，不引入额外框架或依赖。

### 文字与布局分别适配

字体使用rem比例与无单位行高，不重写根字号；浏览器支持时通过text-scale元数据接收系统文本偏好，未支持的浏览器仍可使用审阅字号。手动倍率与浏览器根字号共同决定内容密度：小于125%为标准，125%～不足175%为大字，175%起为超大字。字体根尺寸变化有独立观察入口；不再通过放大整张电视画布来模拟字号变化。原生系统字号的当前验收范围见 [VALIDATION](../VALIDATION.md#tv-v4-组件化重设计)。

| 内容     | 标准 | 大字（含130%／150%） | 超大字（200%审阅） |
| -------- | ---- | -------------------- | ------------------ |
| 常规片库 | 6列  | 5列                  | 4列                |
| 搜索结果 | 4列  | 3列                  | 2列                |
| 榜单内容 | 5列  | 4列                  | 3列                |
| 选集     | 10列 | 8列                  | 6列                |
| 首页续播 | 3列  | 2列                  | 2列                |

首页默认推荐带减小装饰海报和标题间距，优先显示片名与分类。大字保持海报约132逻辑像素的最大宽度，不随字号一起膨胀；重点推荐改为标题／操作并排的紧凑行，隐藏重复的装饰海报，把空间留给片名和内容。搜索左栏独立滚动、输入框固定可见；超大字键盘改五列。超大字下历史与组件板转单列、日期条保留紧凑横滚、扫码区上下排列，操作行和确认按钮允许换行。所有现有动作保留，不重设重复筛选或设置入口。

### 画布与浮层契约

`--canvas-inline`／`--canvas-block`是画布尺寸来源，ResizeObserver按可用区域计算一次`--fit`。页面和提示处于同一缩放容器；原生dialog仍走浏览器模态层，使用同一倍率并锚定电视画布中心。安全区统一作用于页头、正文、播控与播放面板，背景及视频可铺满画布。安全区不是手机触控规范，本原型仍以遥控器操作为目标。

## 遥控交互

同一控件只显示一层焦点框；输入框编辑前的入口与编辑后的原生输入交接焦点，不同时高亮父子两层。持久选中使用填充，与当前焦点分开。普通标题、图片、说明和容器不成为动作焦点；长正文的显式阅读停靠点保留滚动／读屏能力，确认不触发动作，视觉弱于可点击控件。禁用和等待中的控件不可激活，恢复后重新进入方向导航。

方向键按空间位置移动；不触发导航或重播。确认才提交动作。长内容页自动把焦点滚入可视区。返回依次消解原生对话框／播放面板、播放控件、子页，再回来源；恢复来源卡片和滚动位置。根级返回有退出确认。Tab／鼠标也可审阅。搜索输入不拦截输入法组合中的确认。

播放器：确认切换暂停；下键显示控制栏；上键打开选集。进度条方向键预览，确认提交，返回取消。片源未返回清晰度列表时不制造清晰度档位。样例播放器不加载或宣称真实解码。

## 验证与未验证

本轮在真实Chromium浏览器验证18页×深浅色×100%／130%／200%共108种页面组合；另以保守安全区、200%字号验证67状态×深浅色共134种组合。未发现页面横向溢出、可见按钮／标题裁切、破图或无名按钮；“我的片库”的1像素隐藏标题是有意的屏幕阅读器文本，检查中单独排除。状态检查不代表真实服务流程通过。

浏览器分别模拟1280×720、1920×1080、3840×2160、1366×768、1024×768：逻辑画布均为960×540；前三档倍率为1⅓／2／4，4:3窗口居中留边。各档模态层均按画布中心和倍率定位，Escape关闭后返回播放入口焦点。这是浏览器画布验证，不是五台设备或4K原生宿主验收。

本轮实际操作覆盖搜索→详情→播放→选集→返回详情→原搜索，输入及原卡片焦点保留；关闭选集恢复其入口焦点。200%键盘方向键从A走到Z时输入仍可见，焦点滚入视区；200%下进入991–1000分组并选择末集，标题更新且下一集禁用。减少动效模拟下，播放面板animation为none、transition为0s。原有隐藏播控inert、进度预览取消和本地表单逻辑保留；本轮不将未重走的旧流程扩大为新的真实服务验收。浏览器错误日志为空。

现有原型资源校验通过（4个原入口、11部目录、图片与来源、全部脚本语法）；v4另核对入口资源与方案链接，并在真实浏览器检查。上述为**已删除的浏览器稿**在原型阶段的证据，不描述当前入口；生产的 token 几何现由 [layout-contract 测试](../../packages/app/test/layout-contract.tsx)在真实应用上断言，实际宿主证据统一见 [VALIDATION](../VALIDATION.md#tv-v4-组件化重设计)。

本轮截图与矩阵存于本机 `artifacts/tv-redesign-v4/adaptation/`，不纳入产品提交；旧截图不作为本轮适配的当前证据。原生屏幕阅读器、真实OS文本偏好、长按遥控及视频解码均未验收。MVP 的 TV 宿主为固定 API34 AVD 模拟器；物理电视观看距离按平台限制记录。支持与打赏、应用推荐已由用户排除，原型中的对应页面与本节原先的未配置态说明一并作废。

以上仅记录浏览器设计原型的验证范围，不宣称生产或真实服务验收通过。

审阅工具栏可直接切换页面、状态、外观、字号与安全区。方向键移动，Enter确认，Esc返回；工具栏位于电视画布之外。`review=0`隐藏工具栏；`font=1.3`／`safe=overscan`可直接复现大字／保守安全区，去掉review参数即可恢复工具栏。Agent可使用`#review-screen`／`#review-state`／`#review-font`／`#review-safe`审阅同一页面，不另造截图专用实现。个人状态只保存在本次页面内存中，刷新后重置。

### Modern Web Guidance

- `dialog`：应用 “native `<dialog>`” 与 “no focus trap” 的原则，使用 showModal、原生 Escape／焦点返回、aria-labelledby 和浮层 overscroll containment。
- `ime-safe-enter-submit`：应用 “Explicit submit button” 的原则，搜索由原生表单提交；全局遥控键处理先检查 isComposing／229，避免输入法确认误触动作。
- `respect-os-text-scale`：本轮使用rem与浏览器text-scale入口，遵守“DO NOT explicitly set the root font-size”，避免固定根字号或手动重复应用OS倍率；未支持的浏览器保留审阅倍率。
- `form-factor-adaptation`：本轮按“Use min-block-size instead of a fixed height”让控件随文字增高，并为搜索滚动区预留固定输入框的空间，避免焦点被遮挡。TV画布仍按电视比例审阅，不宣称是手机触控布局。

实施时将已确认的视觉规则映射到DESIGN.md及其生成链；候选原型不直接覆盖生产主题。
