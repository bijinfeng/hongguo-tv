应用内颜色引用语义变量；播放器另有 cinema、on-cinema、cinema-muted、cinema-control、scrim 角色。渐变只用于封面和播控的文字可读性。未新增装饰投影、渐变文字或标题上方的装饰标签。

桌面正文为 14–16px、内容标题 18–24px、页面标题 26–32px；TV 正文与操作为 20–24px、栏目标题 28px、页面标题 44px、内容展示标题 48px。以上是浏览器原型的 CSS 像素，尚未映射或验证为 Android TV dp/sp。主控件与海报使用 12px 圆角，头像为圆形；进度条、开关、评审工具和旧辅助组件保留局部几何。TV 主要操作至少 60px 高；桌面媒体图标按钮为 44px 点击区。

这些字体尺度与局部圆角是原型提案，不是根目录 DESIGN.md 已接受的生产标准。检测器的相应建议保留在评审记录中，不通过添加全局忽略或修改生产规范使其消失。

## 焦点和播控

- 选中状态用底色／文字表达，TV 当前焦点用独立外轮廓表达；焦点不放大卡片或挤动布局。
- 页面返回保存来源控件、滚动位置及选集区间；弹层关闭恢复触发控件。主导航与内容区分别可达。
- TV 播放器先收起最上层面板，再处理进度预览、控制层和页面返回。控制层隐藏时，确认键唤起；左右方向键发起定位预览，确认提交、返回取消。
- 控制层显示时，进度滑杆可直接调整；下一集受已上线集数限制。媒体播放键仅模拟状态，不播放音视频。
- TV 搜索输入框可用下方向键离开；选项内上下调整、左右或确认离开。文本区在末尾可向下离开。正式 NSH 实现需按宿主输入法和原生选项控件重新验证。
- TV 修复约定：普通单行输入上下键转移焦点，左右键保留光标编辑；输入法组合期间不拦截按键。只读演示号码不进入焦点路径。影院播控／定位键仅归播放页，刷剧浏览页遵循普通导航与一次返回。
- 同一剧目的选集面板保留来源焦点。开始观看／指定集从零开始，续播显式读取该剧保存的集数与位置，不继承其他剧目的时间。
- TV 找剧将类型、题材、排序收敛为一排具名选择框；结果先于排行榜、上新日历、刷剧等栏目入口。筛选与排序语义由桌面和 TV 共用同一派生函数。

TV 本轮动效清单：筛选改变、进度初始化及阅读位置恢复沿用即时状态更新；不新增动画。选择框沿用原生选项交互与现有焦点外轮廓，影院控制层仍沿用既有透明度过渡及减少动态效果约定。实现后的视觉／宿主验收单独记录。

- 标签组采用 roving tabindex，标签和内容面板关联；对话框使用原生 dialog 的模态焦点边界。
- 桌面收藏、追更和预约使用统一的选中底色与 `aria-pressed`。返回入口采用轻量文字操作，与播放主动作区分。
- 桌面右栏同一剧目、同一上下文面板内的操作保留阅读滚动位置与来源焦点；切换剧目、面板、季或集数区间时重新开始对应内容。选集弹层关闭后保留来源焦点。
- 桌面全屏保留播放器宿主及画面节点，播控动作只更新内部状态；画面占满播控以外的高度，保留等比显示。播控内提供选集与退出全屏入口。弹层焦点按当前面板查找，避免落到背景右栏的同名输入框。
- 不提供评论、剧评、回复、点赞或弹幕交互。找剧排序只作用于筛选后的列表，重复选择保持顺序，热度、最新和收藏分别使用独立演示字段，不改变首页或榜单。

本次未新增动效：全屏切换由浏览器负责，播控状态原位更新，选集沿用既有面板及减少动态效果约定。全屏修复仅完成部分宿主观察，剩余验证按用户要求停止，详见 [desktop-review-fixes.md](desktop-review-fixes.md)。

## 原型状态与工程

`app.js` 管演示模型、动作、路由、返回和焦点；`desktop.js`／`desktop.css` 与 `tv.js`／`tv.css` 分别管页面和组合。公共控件由 `shared/controls.js`、`shared/*.css` 管理；`styles.css` 与端侧 CSS 仅在 `prototype-layout` 层管理布局和辅助页面。两个宿主壳同时只有一个显示，隐藏端的内容被清空，避免重复控件和不可见焦点。

未引入 React、Vite 或 npm UI 依赖。使用项目已有 Oxfmt 检查原型格式，JavaScript 通过语法检查。设计稿本地启动：

```sh
node design/prototype/serve.mjs
```

两端筛选排序与续播、TV 输入／返回、弹层焦点、阅读滚动及安静观看范围的回归入口：`node --test design/prototype/prototype.test.mjs`。

访问 `http://127.0.0.1:4178/`；TV 为 `http://127.0.0.1:4178/?platform=tv`。顶部评审工具提供页面地图、主题、平台与正常／加载／空／失败状态。

原型内剧目、封面、统计与账号均为样例；数据只在内存保留，刷新复原。登录、预约、同步、支付及更新均不连接真实服务；二维码不可扫描。点击模拟播放才将新剧加入演示历史，进入静态播放器本身不作为实际观看。

2026-11-14 账号与设置补充：扫码覆盖准备、确认、过期、失败与不可用；手机号覆盖14个源码区号、验证码失败／等待及额外短信验证；TV 数字键盘和同局域网输入仅操作演示值，不创建配对会话或凭据。合并登录前历史需要显式确认，失败保留账号和游客原记录。设置选项只保存在本次演示，语言选择不会翻译当前原型，解码、预取和电视首页频道不会调用宿主能力；正式实现须按实际宿主提供选项，保存失败和下次播放生效分开反馈。
