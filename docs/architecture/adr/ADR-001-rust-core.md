# ADR-001：统一Rust核心

状态：Accepted（架构方向）；原提案：2026-11-13。接受决策不表示全部业务已迁移或验收。

## 决策与原因

NSH TSX负责界面，同一Rust library承接内容协议、账号、媒体和持久化，HTTP与原生bridge作为外层适配。pnpm／Cargo保留各自依赖图，由统一工程入口编排。

这样能让Web与原生共享业务语义，同时避免Go服务／mobile binding进入最终安装、正常开发和发行依赖。迁移按固定上游行为与去敏向量逐项重写，保留可比较证据；不读取旧客户端私有数据。

## 代价与边界

Rust重写不自动继承旧实现正确性；必须补契约、存储、并发、平台宿主与真实流程验收。Go只作迁移期参考，达到[退役门槛](../../../ARCHITECTURE.md#迁移与退出条件)后移出旧链路。行为细节和当前进度不在ADR维护。
