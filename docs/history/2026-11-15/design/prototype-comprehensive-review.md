## 设计专属性与保留项

续播集数／时间、竖版封面和 TV 影院区与短剧观看有关；原来的边框网格与筛选组合则可直接替换成普通后台，产品个性较弱。此次用主续播的封面、观看动作与紧凑次卡建立明确观看入口，保留已有内容素材和功能事实。

有效基础有三点：克制色彩适合安静观看；续播明确到集数和位置；TV 焦点轮廓独立于选中状态，并已有逐层返回、滚动和来源恢复机制。没有补回评论、弹幕、点赞或离线任务。

## 五项优先问题与处理

| 优先级 | 问题与用户影响                                                 | 本轮处理                                                          | 对应方法                    |
| ------ | -------------------------------------------------------------- | ----------------------------------------------------------------- | --------------------------- |
| P1     | 筛选展开八排，剧目被推出首屏，增加滚动与遥控成本               | 桌面高级项收敛为五列具名选择器；TV 主筛选与更多同行，减少重复分隔 | impeccable distill / layout |
| P1     | 两条续播同权、横向空间浪费，推荐内容首屏不完整                 | 第一条作为主观看入口，第二条紧凑；收紧栏目间距与海报宽度          | impeccable layout / polish  |
| P1     | TV 详情头图裁掉人物眼睛与额头，破坏内容识别                    | 调整取景位置，观察两部样例面部完整性                              | impeccable polish           |
| P2     | 筛选、选集重描边，界面像管理表单；切换收藏使旁边动作位移       | 公共控件减重；当前集与焦点分开表达；收藏宽度固定                  | impeccable quieter / polish |
| P2     | 搜索按钮错位，空输入仍有清空；连续操作中草稿、取消与焦点不可靠 | 公共表单对齐；空值隐藏清空；修复下列状态缺陷                      | impeccable harden           |

交互缺陷单独记录，避免视觉通过掩盖状态问题：

- TV 登录数字键盘返回先取消当前输入子层，恢复旧值与来源焦点，再次返回才退出登录。
- 验证码同步演示草稿，获取／重发后保留；无障碍名称不再混入发送按钮文字。
- 删除收藏后定位相邻存活项；最后一项删除后定位“去找剧”，不落到文档。
- TV 音量与组件板滑杆采用确认进入、预览、确认提交、返回取消；失焦、窗口失活、页面隐藏及 pointer cancellation 回滚。
- TV 收藏、追更、预约与桌面统一 `aria-pressed`；组件板清空搜索时移除过期校验提示。

公共样式归 `shared/`，新主续播同时展示在组件板，页面只组合布局。工程上没有引入新 UI 依赖；新增交互回归集中覆盖可观察状态与恢复规则，便于开发者与后续 Agent 定位行为契约。

## 认知负荷与使用路径

基线负荷中等，主要低谷是找剧：题材有六个可见选项，加上多组高级筛选，决策点明显超过四项。此次保留高频题材直接选择，把低频维度收进具名选择器；选集仍按区间分页，避免一次展示全部集数。未用额外说明标签代替布局。

熟练用户的风险是筛选滚动、收藏目标位移和返回丢焦；首次用户的风险是“首页／精选”等端侧命名差异、观看动作不够突出；键盘与低视力用户的风险是中断编辑残留和来源焦点丢失。本轮修复后者中的可复现缺陷，但真实读屏、系统字号与观看距离仍需验证。

情绪路径：TV 初始影院区较强，找剧表单是低谷，详情回到内容，播放局部连贯。此次重点降低找剧低谷、把桌面第一屏直接接到继续观看。样例封面和有限片库不能证明真实内容规模下的推荐质量。
