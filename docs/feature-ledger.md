## 状态更新规则

每项细分状态使用“待核对、待实现、已实现待宿主、已验收、平台不适用”；证据必须能关联实际源码与运行。上表已更新 A、B4b 与 B4c 的实际实现状态；未通过的宿主／发行项仍保持缺口，不从其他链路继承验收。默认回归使用去敏 fixture；页面 ID 由剧目／视频身份派生，禁止使用随机或回收行索引作为身份。

UI 所有者：`packages/ui` 管外观、控件与动效，`packages/app` 管双端组合和共享业务；`apps/*` 只装配。新增行为同时补对应层回归、运行命令与失败边界，避免为开发者和 Agent 形成另一套含糊状态。
