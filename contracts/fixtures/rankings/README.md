# Anonymous official-ranking fixtures

Synthetic values follow fixed `lists.go::RankList/rankOptions` and `lists_test.go::TestRankJSONSelectorsAndActors` at the manifest commit. No Go execution, real account, credential, tracking URL or live response is used; `secret` marker fields test omission. Synthetic paths on allowlisted image hosts are never fetched by these tests.

The page deliberately includes a drama and actor with the same decimal ID, duplicate records, a creator album, disabled video and a nested selector/panel. `page.expected.json` is the reviewed public contract, not a parser-generated snapshot. Actor IDs never become playable series IDs, and summary episodes are absent. Raw service offset20 is independent of two visible items.

Row fields follow the live feed (checked 2026-11-19 against `cell/change/v` with `--anonymous-live`): a drama row carries `title`, `video_desc`, `episode_cnt`, a display-ready `sub_title` ("逆袭·全319集") and its heat line at `rec_text_item.RecommendText`. The detail-page aliases `series_title`, `series_intro` and `heatText` are **not** sent by this endpoint, and neither is any position field: the feed supplies no rank, so the page never fabricates one. `rank` therefore stays absent from the fixture's expected items and the UI keeps no empty rank lane. Heat is the service's own text ("8907万热度"), never a computed score.

`cargo test -p hongguo-core rankings` covers exact selector/query bytes, tab26/18, service/cell cursor fallback, empty advancement, limits and malformed/stalled responses. Transport tests reuse the anonymous signed request harness, check ephemeral identity/signature headers and absence of credentials, device registration or history writes. Native tests compare HTTP/native success/failure, input rejection and cancellation/session close.

Explicit optional anonymous read-only smoke: `cargo run --locked -p hongguo-core --example rankings_probe -- --anonymous-live`. It prints aggregate counts only and never runs in the offline suite. Live variability or successful probe does not verify a ranking UI, full series relationship, radar, media playback or physical TV.

On 2026-11-19 the probe resolved real pages for `all/ranklist_hot_play_sc`, `ranklist_celebrity/ranklist_actor_fans` and `series_album/series_album_new_rank` (10 dramas, 20 actors, 10 dramas), and a macOS host rendered the desktop rankings page from that live API: service titles, descriptions, heat lines ("8907万热度"), `sub_title` metadata and the four server selector rows. That is a single-host, single-session observation; physical TV, other hosts, slow networks and later upstream changes are still unverified.
